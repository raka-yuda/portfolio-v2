## Behind the scene

My aiming with this project actually is for finishing my college degree, but beside that, i don’t want this project is purely only for completing purpose, i want to give a personal touch to be a meaningful project, at least for me, and it could be an evidence for me has been building a fully functional app from scratch including the idea and tech side.

For full story how i make it from scratch could read this http://localhost:3000/blog/your-content-trending-then, but in short i want to build something that could be useful for me and maybe other people, and also i want to learn more about how to build a fullstack app, so i think this project is a good fit for that.
