## Why

Every cloud-first notes app I've tried eventually started getting in my way: weird syncing, vendor lock-in, surprise pricing changes. Paperbase is my reaction to that — markdown files on disk, optional sync, nothing more.

## Architecture

A small Tauri shell hosts a React editor. Sync is a Rust daemon that talks over the Tailscale tailnet, so there's no SaaS server in the loop at all.

## Crypto

Files are encrypted with age before they leave the device. Keys are stored in the OS keychain. If the daemon dies you still have the plaintext files locally — encryption is purely for transit and remote storage.
